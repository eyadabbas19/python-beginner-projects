# Vehicle Gearbox Calculator

A Python project that simulates basic gearbox performance in an automotive powertrain.

## Features

- Calculates wheel torque after gearbox efficiency losses.
- Calculates wheel rotational speed.
- Calculates tractive force.
- Calculates motor input power.
- Calculates wheel output power.

## Engineering Concepts

This project applies:

- Gear reduction ratios
- Torque multiplication
- Rotational speed
- Mechanical power
- Gearbox efficiency
- Tractive force

## Technologies

- Python
- Math module

Developed as part of my independent automotive engineering studies to apply mechanical engineering principles through programming.
