# Python Beginner Projects

A collection of my first Python projects, built while learning programming fundamentals and applying them to practical problems.

## Projects

### 1. Football Sprint Analyzer

A simple program that asks for a user's name and 20-metre sprint time, calculates their speed in kilometres per hour, and displays the result.

**Concepts practised:** User input, variables, numeric conversion, arithmetic, and formatted output.

### 2. Investment Calculator

A program that calculates the profit from an initial investment using an annual return rate and displays the resulting total capital.

**Concepts practised:** Functions, parameters, return values, arithmetic, and formatted output.

### 3. Expense Detective

A monthly budgeting program that records three expenses, calculates total spending and the remaining budget, and determines whether spending is within budget.

**Concepts practised:** User input, arithmetic, conditional statements, and basic input validation.

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the folder containing the desired Python file.
4. Run the program using:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python file you want to run.
